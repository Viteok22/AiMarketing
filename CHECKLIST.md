# Чек-лист перед демо

## 1. DeepSeek API и anymodel

- [ ] Есть рабочий DeepSeek API key.
- [ ] Есть рабочий anymodel API key для GPT Image 2.5.
- [ ] Запустить `.\scripts\configure.ps1` (ключи вводятся скрыто).
- [ ] Проверить текст: `.\.venv\Scripts\python scripts\check_deepseek.py` → `"ok": true`.
- [ ] Проверить изображение: `.\.venv\Scripts\python scripts\check_image.py` → `OK`.
- [ ] Если ключ от другого OpenAI-совместимого шлюза — указать его `DEEPSEEK_BASE_URL` и `DEEPSEEK_MODEL`.
- [ ] Для anymodel проверить `ANYMODEL_BASE_URL`, `ANYMODEL_IMAGE_MODEL` и `ANYMODEL_IMAGE_QUALITY=low`.
- [ ] Проверить баланс anymodel: при `HTTP 402` пополнить или оставить `low`.

## 2. Telegram

- [ ] @BotFather → `/newbot` → имя и username → скопировать токен.
- [ ] Создать тестовый канал (например, «Салаватстекло — демо»).
- [ ] Добавить бота в канал администратором с правом «Публикация сообщений».
- [ ] Узнать свой user ID у @userinfobot.
- [ ] Запустить `.\scripts\configure.ps1` и заполнить:
  - `TELEGRAM_BOT_TOKEN`
  - `TELEGRAM_CHANNEL_ID`
  - `TELEGRAM_PROXY` (если `api.telegram.org` недоступен)
  - `ADMIN_TELEGRAM_ID`
  - `ADMIN_PASSWORD`
- [ ] Проверить: `.\.venv\Scripts\python scripts\check_telegram.py`
- [ ] Убедиться, что в конце вывода `OK: бот может публиковать в канал.`

## 3. Запуск

- [ ] `.\restart.ps1`
- [ ] Открыть http://127.0.0.1:8000
- [ ] Войти по `ADMIN_PASSWORD`
- [ ] Проверить `/health`: `generator_started=true`, `image_configured=true`, `bot_started=true`
- [ ] Убедиться, что `DATABASE_PATH=./data/app.db` и файл создаётся
- [ ] В Telegram отправить боту `/start`

## 4. Прогон сценария

- [ ] Отправить задачу: «Подготовь пост про архитектурное стекло для фасадов бизнес-центра. Акцент на естественный свет и энергоэффективность. Аудитория — архитекторы и проектировщики.»
- [ ] Дождаться одного текста, одного фото и кнопок «Другой текст/фото».
- [ ] Нажать «Другой текст» и «Другое фото» — проверить, что контент меняется в том же сообщении.
- [ ] Нажать «⚡ Быстрые правки» → «Короче» — проверить, что добавился третий вариант текста, старые доступны, фото осталось.
- [ ] Нажать «На доработку», отправить комментарий, получить новую партию вариантов.
- [ ] Выбрать лучший текст и фото, нажать «Одобрить выбранное».
- [ ] Проверить пост в канале: это одно сообщение — фото + подпись, а не два отдельных поста.
- [ ] Поставить реакции 👍 ❤️ 👎 и нажать «📊 Статистика» — проверить просмотры, реакции и посты вне бота.
- [ ] В «Аналитике» нажать «Обновить просмотры» — проверить, что появились просмотры.
- [ ] Нажать «AI-вывод» — проверить рекомендации по постам.
- [ ] Переключить фильтр компаний в «Аналитике» и «Трендах».
- [ ] В согласовании нажать «Время», выбрать «+1 час» — проверить статус «Запланировано»; затем отменить публикацию кнопкой.
- [ ] В карточке компании включить автопостинг на 2–3 минуты, дождаться автоматического черновика, выключить автопостинг.
- [ ] Открыть «🗓 Контент-календарь», добавить тему на ближайшее время, нажать «Сгенерировать» — черновик должен прийти в Telegram.
- [ ] В боте нажать «🗓 Календарь» — проверить тему и статус.
- [ ] Нажать «🔥 Тренды» — проверить выводы и 3 идеи.
- [ ] Открыть страницы «Аналитика» и «Тренды» в панели.
- [ ] Перезапустить `.\restart.ps1`, открыть панель — задачи, варианты и история должны остаться.
- [ ] Создать второй черновик и нажать «Отклонить» — проверить, что поста в канале нет.
- [ ] Отправить вопрос: «Почему ты выбрал такой заголовок и какие факты использовал?»
- [ ] Проверить, что ответ учитывает историю.

## 5. Если что-то не так

| Проблема | Решение |
|---|---|
| Бот молчит | Проверить токен и `TELEGRAM_PROXY`, перезапустить `restart.ps1` |
| DeepSeek 401 | Проверить ключ, base URL и модель; для официального API — `https://api.deepseek.com/v1` и `deepseek-chat` |
| anymodel 401 | Проверить `ANYMODEL_API_KEY` и `ANYMODEL_BASE_URL` |
| anymodel 402 | Пополнить баланс или оставить `ANYMODEL_IMAGE_QUALITY=low`; при 1 фото использовать «Ещё фото» |
| Нет реакций в `/stats` | Нажать «Обновить»: статистика подтягивает реакции из `t.me/s`, пост должен быть публичным |
| Тренды не обновляются | Проверить VPN/прокси и доступ к `t.me/s`; нажать «Обновить анализ» |
| Нет прав в канале | Добавить бота админом с «Публикация сообщений» |
| Ошибка 409 при запуске бота | Закрыть другой экземпляр бота/приложения |
| Панель не открывается | Проверить порт 8000 и лог процесса |

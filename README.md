# Автономный AI-маркетолог

Администратор создаёт компанию и загружает знания, клиент ставит задачу в Telegram, AI готовит 2 варианта текста и 2 изображения, показывает по одному с переключением, отправляет на согласование, публикует выбранный вариант только после одобрения, собирает реакции и анализирует популярные публичные каналы.

## Что уже работает

- **Веб-панель:** создание компаний, загрузка TXT/MD/PDF, добавление текста с сайта, привязка Telegram-пользователя, задачи, аналитика с фильтром по компании, тренды, автопостинг по расписанию, недельный контент-календарь.
- **Telegram-бот:** задача обычным языком → AI генерирует 2 текста + 2 изображения, в чате показывает 1 текст + 1 фото → кнопки «Другой текст», «Другое фото», «Ещё фото» → «Одобрить выбранное», «На доработку», «Отклонить». Постоянное меню внизу: «Новая задача», «Статистика», «Тренды», «Запланировано», «Календарь», «Стиль», «Помощь». Каждый менеджер видит только одну компанию — ту, которую назначил администратор; переключения компаний в боте нет.
- **Быстрые правки:** в карточке черновика кнопка «⚡ Быстрые правки» — короче, другой заголовок, добавить цифры, проще, экспертнее, усилить CTA. Каждая правка добавляет новый вариант текста, старые остаются доступны кнопкой «Другой текст»; изображение не меняется.
- **Контент-календарь:** на неделю вперёд, с датой, темой и получателем. В назначенное время планировщик сам создаёт черновик и присылает его на согласование.
- **Approval gate:** без явного одобрения публикация невозможна; после правок снова требуется согласование.
- **Реальная публикация** в Telegram-канал одним постом: фото + подпись с жирным заголовком, короткими абзацами, маркерами и хештегами. Длинный текст аккуратно подрезается под лимит подписи Telegram.
- **Текст:** DeepSeek API (OpenAI-совместимый `/chat/completions`).
- **Изображения:** anymodel GPT Image 2.5, `quality=low` по умолчанию. Бот делает графические SMM-креативы в фирменных цветах: логотип, крупный заголовок, карточки, 3D-стекло. Фотографии людей не используются. Заглушек нет: если изображение не сгенерировалось, задача завершается ошибкой и не публикуется.
- **Стиль заказчика:** `/style` или кнопка «📌 Стиль» — сохранить примеры постов (текст, фото с подписью, пересланное сообщение). Бот учитывает их тон, структуру и визуальный стиль в новых публикациях.
- **SQLite:** компании, задачи, варианты, история диалога, привязки, публикации, реакции, расписания, просмотры и AI-выводы сохраняются после перезапуска. Файл — `data/app.db`.
- **Автопостинг:** расписание на компанию (интервал, тема, получатель) само создаёт черновик и присылает варианты на согласование. Публикация — только после одобрения.
- **Отложенная публикация:** в карточке согласования можно выбрать «сейчас», «+1 час», «+3 часа», «завтра в 10:00» или ввести своё время вручную (`15.11 18:30`, `15.11.2026 18:30`, `через 2 часа`); пост публикуется планировщиком.
- **Обратная связь:** реакции и просмотры из `t.me/s`, включая посты, опубликованные вне бота; `/stats` и кнопка «Статистика» сами обновляют метрики, планировщик делает это каждые 5 минут. Ежедневный отчёт, AI-вывод «что зашло и что улучшить», учёт в следующих промптах.
- **Анализ трендов:** сбор популярных постов из публичных каналов через `t.me/s`, отдельный инсайт для каждой компании, 3 оригинальные идеи. `/trends` и страница «Тренды» с фильтром по компании.
- **Изоляция компаний:** у каждой компании свой профиль, знания, канал, задачи и история. Каждый менеджер привязан к одной компании и не может переключаться между компаниями в боте.
- **Работа через локальный HTTP-прокси** для Telegram, если `api.telegram.org` недоступен напрямую.

## Архитектура

Один процесс Python:

```
FastAPI (веб-панель)       ─┐
aiogram 3 (Telegram)       ─┼─> SQLite (data/app.db)
Scheduler (автопостинг)    ─┤
DeepSeek API (текст)       ─┤
anymodel GPT Image 2.5     ─┤
TrendAnalyzer (t.me/s)     ─┤
Analytics (просмотры/AI)   ─┘
```

- `app/admin.py` — веб-панель, знания, аналитика, тренды.
- `app/telegram_bot.py` — Telegram, варианты, согласование, публикация, реакции.
- `app/generator.py` — DeepSeek-клиент, 2 варианта текста и изображений.
- `app/image_gen.py` — anymodel GPT Image 2.5.
- `app/trends.py` — парсер публичных каналов и AI-анализ трендов по компаниям.
- `app/analytics.py` — просмотры из `t.me/s` и AI-вывод по публикациям.
- `app/scheduler.py` — автогенерация по расписанию, контент-календарь и отложенная публикация.
- `app/db.py` — SQLite-схема и подключение.
- `app/store.py` — репозиторий компаний, задач, вариантов, истории, реакций, календаря и трендов.
- `app/prompts.py` — промпты, парсинг, классификация «задача/вопрос».
- `app/config.py` — настройки из `.env`.

## Быстрый старт

### 1. Зависимости

Нужен Python 3.12.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

Либо просто запустите `.\run.ps1`: он сам создаст `.venv` и установит зависимости.

### 2. Настройки

```powershell
Copy-Item .env.example .env
```

Заполните в `.env`:
- DeepSeek/anymodel base URL, модель и API keys;
- Telegram-токен, канал, ваш user ID и пароль панели.

Секреты сохраняются только в `.env`, файл в `.gitignore`.

Минимальный `.env`:

```ini
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHANNEL_ID=@your_test_channel
TELEGRAM_PROXY=http://127.0.0.1:10809
ADMIN_TELEGRAM_ID=123456789
ADMIN_PASSWORD=...

DATABASE_PATH=./data/app.db

DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_MODEL=deepseek-chat

ANYMODEL_BASE_URL=https://anymodel.org/v1
ANYMODEL_API_KEY=...
ANYMODEL_IMAGE_MODEL=gpt-image-2.5
ANYMODEL_IMAGE_QUALITY=low
```

`quality=low` выбран по умолчанию: `medium`/`high` стоят заметно больше токенов anymodel и могут упереться в баланс.

### 3. Telegram-бот и канал

1. @BotFather → `/newbot` → имя и username.
2. Скопируйте токен в `TELEGRAM_BOT_TOKEN` в `.env`. Не присылайте токен в чат.
3. Создайте тестовый канал, добавьте бота администратором с правом «Публикация сообщений».
4. Укажите канал в `TELEGRAM_CHANNEL_ID` или в карточке компании.
5. Если `api.telegram.org` не открывается напрямую, укажите `TELEGRAM_PROXY`.

Проверка: после запуска отправьте боту `/start` — он должен ответить и показать меню.

### 4. Запуск

```powershell
.\run.ps1
```

Панель: http://127.0.0.1:8000
Пароль: `ADMIN_PASSWORD` из `.env`.

Проверка состояния:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

В ответе должно быть `ok=true`, `generator_started=true`, `image_configured=true`, `bot_started=true`.

## Демонстрация

1. Админ открывает панель, показывает компанию «Салаватстекло» и знания.
2. В Telegram отправляет задачу про архитектурное стекло для фасадов бизнес-центра.
3. Бот принимает задачу и генерирует **2 варианта текста и 2 изображения**.
4. В чате показывается **один текст и одно фото** с кнопками:
   - «Другой текст (1/2)», «Другое фото (1/2)» — переключение без листания;
   - «Ещё фото» — дополнительный вариант;
   - «Одобрить выбранное», «На доработку», «Отклонить».
5. Нажимаем «На доработку», пишем комментарий — бот генерирует новую партию, старое сообщение заменяется новым.
6. Переключаем текст/фото, нажимаем «Одобрить выбранное» — пост уходит в канал одним сообщением: фото + оформленная подпись.
7. После публикации ставим реакции в канале и нажимаем кнопку «📊 Статистика» — она сама подтягивает просмотры и реакции из `t.me/s`, включая посты вне бота.
8. Кнопка «🔥 Тренды» или страница «Тренды» показывает разбор популярных каналов и идеи.
9. Перезапускаем приложение — задачи, варианты, история, реакции, расписания и метрики остаются в SQLite.

Дополнительно:
- в карточке компании включить **автопостинг** с интервалом 2–3 минуты — AI сам пришлёт черновик;
- в согласовании нажать **«Время»** и выбрать «+1 час» или «Завтра 10:00» — пост опубликует планировщик;
- в **«Аналитике»** нажать «Обновить просмотры» и «AI-вывод» — появятся просмотры и рекомендации;
- переключить фильтр компаний в «Аналитике» и «Трендах» — данные не смешиваются.

Проверка запрета публикации: создать второй черновик и нажать «Отклонить» — поста в канале не будет.

## Про AI-генерацию: честно

- Текст: DeepSeek API. Промпт включает факты о компании, историю, реакции на прошлые посты и свежие тренды. Оформление — Telegram HTML: жирный заголовок, короткие абзацы, 3–5 маркеров, вопрос к аудитории и хештеги. Объём 600–850 знаков; подпись подрезается до 1000, чтобы пост был одним сообщением.
- Изображения: anymodel GPT Image 2.5 по английскому промпту, который DeepSeek возвращает вместе с публикацией. Бот делает графический SMM-креатив: логотип, крупный заголовок, подзаголовок, карточки и 3D-стекло; фотографии людей не используются. Нужен рабочий ключ anymodel в `ANYMODEL_API_KEY`.
- Если изображение не сгенерировалось, бот сообщает ошибку, задача не переходит к публикации, заглушки не используются.

## Хранение данных

- `data/app.db` — SQLite (WAL). Таблицы: `companies`, `tasks`, `variants`, `history`, `user_company`, `publications`, `reaction_state`, `reaction_counts`, `trend_sources`, `trend_posts`, `trend_insights`, `schedules`, `post_metrics`, `channel_posts`, `analytics_insights`, `style_examples`.
- После перезапуска сохраняются компании, задачи, варианты, выбранные варианты, история, привязки, публикации, реакции, тренды, расписания, просмотры и AI-выводы.
- Задачи в статусе `drafting` при старте помечаются ошибкой с кнопкой «Повторить».
- Задачи в статусе `publishing` при старте помечаются ошибкой «проверьте канал»: пост мог уйти до сбоя.
- Кнопки согласования у `pending_approval` задач и запланированные публикации продолжают работать после рестарта.
- Кнопка «Сбросить демо» очищает базу и возвращает стартовую компанию.

## Безопасность и ограничения

- Секреты только в `.env`, файл в `.gitignore`. В коде нет токенов и паролей.
- Публикация возможна только после явного одобрения.
- Проверка прав: одобрять может автор задачи или `ADMIN_TELEGRAM_ID`.
- Для загрузки с сайта блокируются локальные и приватные адреса.
- Размер загружаемого файла — до 5 МБ.
- Данные компаний разделены по `company_id`; пользователь привязан к одной компании.
- SQLite-файл содержит данные клиентов; не коммитьте его в git.

## Что доработать для коммерции

1. PostgreSQL + очередь задач + сохранение FSM-состояния.
2. Контент-календарь на неделю/месяц и автоматическое планирование тем.
3. Пер-компанийные источники трендов (сейчас список публичных каналов общий).
4. Вторая и последующие компании в одном демо-сценарии.
5. VK и MAX: адаптеры публикации и статистики.
6. Полноценный аудит, роли, журнал согласований и отзыв доступов.
7. Резервный image-провайдер и расширенные шаблоны под разные рубрики.
8. Отчёты по заявкам и продажам, а не только по просмотрам и реакциям.
9. Docker/Windows-сервис и автозапуск после перезагрузки.
